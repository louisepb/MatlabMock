# MatlabMock
Demo programs for MATLAB testing with mocks
To launch tests, navigate to test folder and type 'runtests("testname")' on the command line

* **MockingExample**
    * Example of program using mocking for function and properties
* **LaunchAppTest and LaunchAppWithMockTest**
    * Tests for launchApp app, with and without mocking
* **PlotAppExampleTest**
    * Example of app created in app designer with mocked test
